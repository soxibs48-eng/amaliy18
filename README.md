# Kugoo - Официальный интернет-магазин электросамокатов

Проект интернет-магазина Kugoo, сверстанный в соответствии с макетом Figma:
**Figma Design:** [Kugoo + (Node ID: 176-1279)](https://www.figma.com/design/ZwdsP3I9bVTFLyrSeE8QAW/Kugoo-%2B?node-id=176-1279)

## 🚀 О проекте
Полнофункциональный многостраничный адаптивный веб-сайт интернет-магазина электротранспорта Kugoo.

### 📄 Страницы:
- **Главная (`index.html`)** — Баннер, каталог, преимущества, хиты продаж, карточки товаров, отзывы, сервисный центр, подвал.
- **Каталог (`catalog.html`, `catalog-product.html`)** — Категории, фильтрация, карточки электросамокатов.
- **Карточка товара (`product.html`)** — Галерея, характеристики, комплектация, отзывы, заказ в 1 клик.
- **Корзина (`basket.html`)** — Оформление заказа, расчет стоимости.
- **О компании (`about.html`)** — История бренда, миссия и сертификаты.
- **Сервис (`service.html`)** — Ремонт, диагностика и гарантия.
- **Тест-драйв (`test-drive.html`)** — Запись на бесплатный тест-драйв.
- **Блог и статьи (`blog.html`, `article.html`)** — Полезные статьи и советы.
- **Сравнение (`comparison.html`)** — Сравнение характеристик моделей.
- **Избранное (`favourites.html`)** — Отложенные товары.
- **Контакты (`contacts.html`)** — Адреса магазинов, карта, реквизиты.
- **Доставка и оплата (`delivery-pay.html`)** — Условия покупки и доставки.
- **Сотрудничество (`cooperation.html`)** — Оптовые закупки и B2B.
- **Акции (`discounts.html`)** — Скидки и специальные предложения.

## 🛠 Технологии
- **HTML5** (Семантическая разметка)
- **CSS3 / SCSS** (Flexbox, CSS Grid, адаптивность для всех разрешений)
- **JavaScript (ES6+)** (Интерактивные слайдеры, фильтры, табы, модальные окна, аккордеоны)
- **Vercel** (Деплой и хостинг)

## 📦 Развертывание
Сайт оптимизирован для мгновенного развертывания на **Vercel** и **GitHub Pages**.
